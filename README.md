# 浙江树人学院 — 校园数字孪生系统

> 基于 Three.js 的 3D 校园可视化与交互系统

[English](#english) | [中文](#中文)

---

## 项目简介

本项目是浙江树人学院计算机图形学期中作业，采用 Three.js 构建了一个可交互的 3D 校园数字孪生场景。系统还原了学校南北两个校区的建筑、道路、绿化等基础设施，并实现了车辆动画、天气系统、人物交互、AI 模型生成等丰富功能。

**作者**：任亿嘉、郭昱含

---

## 技术栈

| 技术 | 说明 |
|------|------|
| HTML5 + CSS3 | 前端页面结构与样式 |
| JavaScript (ES5) | 核心业务逻辑 |
| Three.js r0.137 | 3D 渲染引擎 |
| GLTFLoader + DRACOLoader | GLB/GLTF 3D 模型加载 |
| Web Audio API | 背景音乐与音效播放 |
| localStorage | 模型状态持久化存储 |
| 腾讯混元3D API | AI 生成 3D 模型 |

## 功能一览

### 🏗️ 3D 场景

- **南北两个校区**：北校区（宿舍区+运动场）、南校区（教学区+食堂+图书馆）
- **28 种建筑类型**：宿舍楼、教学楼、实验楼、图书馆、食堂、行政中心、体育馆、美术馆、产业楼等
- **动态建筑标签**：鼠标悬停显示建筑名称与编号
- **校园道路网络**：灰色柏油路 + 黄色中央分隔线
- **道路绿化**：道路两侧种植行道树

### 🚗 车辆动画

- **汽车**：沿主路东西向行驶，到达端点自动掉头
- **公交车**：沿主路反向行驶，与汽车共享道路
- **平滑转向**：车辆掉头时有自然的旋转动画

### 🌤️ 天气系统

| 模式 | 效果 |
|------|------|
| **白天** | 蓝天白云，强阳光，暖色调 |
| **夜晚** | 深蓝色夜空，低光照，暗色调 |
| **多云** | 灰蓝色天空，柔和光照 |
| **雨天** | 阴沉天空 + **雨滴粒子特效**（1200个粒子，斜向下落） |
| **雪天** | 浅蓝天空 + **飘雪粒子特效**（2000个粒子，随风飘落） |

所有天气切换均有**平滑过渡动画**。

### 🔊 音频系统

- **背景音乐**：校园氛围背景音乐，支持音量调节
- **雨声**：雨天自动播放雨声音效
- **夜声音效**：夜晚自动播放夜间环境音
- 所有音频支持独立开关和音量控制

### 👥 人物系统

| 角色 | 简介 | 可交互 |
|------|------|--------|
| 👧 **女生** | 位于南校区，粉红色上衣 | ✅ 可选中控制 |
| 👦 **男生** | 位于北校区，蓝色上衣 | ✅ 可选中控制 |
| 🏃 **跑步者** | 自动绕操场跑道跑步，有跑步动画 | 悬停显示对话气泡 |

- **人物键盘控制**：选中后可用方向键（女生）或 WASD（男生）在各自校区内移动
- **对话气泡**：悬停人物时显示随机对话台词
- **行走动画**：腿部摆动模拟真实行走姿态
- **智能避障**：行人自动绕开建筑物

### 🎮 AI 模型交互

- **拖拽移动**：点击选中模型后拖拽可调整位置
- **滚轮缩放**：滚动鼠标滚轮缩放模型大小
- **R 键旋转**：每按一次旋转 15°
- **Delete 键删除**：移除选中的模型
- **Esc 取消选中**：取消当前模型选中状态
- **模型持久化**：拖拽/缩放/旋转后的状态自动保存到 localStorage，刷新后恢复

### 🤖 AI 模型生成

支持通过 **腾讯混元3D API** 生成 3D 模型并导入场景：

- **文字生成**：输入描述性文字（如"一只可爱的熊猫"）生成模型
- **图片生成**：上传参考图片生成 3D 模型
- **PBR 材质**：可选启用物理真实材质
- **面数控制**：可调整生成模型的面数（精度）

### 📋 信息面板

- **建筑介绍列表**：点击查看所有建筑，点击某一项跳转到对应位置
- **建筑详情卡**：显示名称、编号、类型、面积、楼层、建成年份、建筑简介
- **Canvas 绘制预览**：每栋建筑配有手绘风格的建筑外观预览图

### 🗺️ 图层控制

可独立控制以下图层的显示/隐藏：

- 建筑物（buildingsGroup）
- 树木（treesGroup）
- 道路（roadsGroup）
- 建筑标签（labelsGroup）
- AI 模型（aiModelsGroup）
- 阴影效果
- 雾效

## 操作说明

### 视角切换

| 按钮 | 功能 |
|------|------|
| **透视视角** | 进入第一人称视角，可通过方向键/WASD 在校园中"行走" |
| **鸟瞰视角** | 俯视整个校园，鼠标拖拽旋转/平移/缩放 |
| **显示/隐藏标签** | 切换建筑名称标签的显示 |
| **重置视角** | 恢复初始相机位置 |

### 人物控制

1. **双击** 女生或男生模型将其选中
2. 按屏幕底部提示使用键盘控制移动：
   - 女生：方向键 ↑↓←→
   - 男生：W A S D
3. **再次双击** 空白区域或按 **Esc** 取消选中

### AI 模型操作

1. 单击选中模型（显示绿色选择框）
2. 拖拽移动位置
3. 滚轮缩放大小
4. 按 **R** 键旋转
5. 按 **Delete** 删除模型

## 运行方式

### 方式一：本地服务器（推荐）

由于项目使用了 `fetch('/api/...')` 接口获取模型列表，需要通过 HTTP 服务器运行：

```bash
# 使用 Node.js
node server.js
# 然后打开 http://localhost:3000
```

### 方式二：直接打开

仅打开 `index.html`（部分功能如自动加载本地文件夹模型将不可用，但核心场景正常）
